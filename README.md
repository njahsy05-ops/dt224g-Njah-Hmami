## Git-frågor
### Vad är skillnaden mellan git add och git commit?
git add används för att välja vilka ändringar som ska sparas. git commit sparar sedan de valda ändringarna i projektets historik.
### Varför använder man branches istället för att arbeta direkt i main?
Branches används för att kunna göra och testa ändringar utan att påverka huvudversionen i main.
### Vad händer rent praktiskt när man gör en merge?
När man gör en merge slår man ihop ändringar från en branch med en annan branch, till exempel från dev till main.
### Vad är skillnaden mellan att pusha till GitHub och att publicera direkt till exempelvis Netlify?
När man pushar till GitHub skickar man sina commits till sitt repository på GitHub. När man publicerar på Netlify gör man webbplatsen tillgänglig på internet.
### Om du vill exkludera en fil från versionshantering, hur gör du då?
Man kan lägga till filen i en .gitignore-fil. Då ignorerar Git filen och den tas inte med i versionshanteringen.
